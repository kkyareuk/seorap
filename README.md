# 서랍마을 작업판

휴대폰에서 서랍마을의 그림, 효과음, 번역, 앱 출시 작업을 확인하는 독립 GitHub Pages 사이트입니다.

## 들어 있는 메뉴

- 요약: 전체 진행률과 지금 먼저 할 일
- 그림: 현재 게임 그림 미리보기, AI 건물 교체 체크리스트, 유형별 필터
- 건물 디자인 도감: 빵집·카페·식당·병원·공연장·상점·학교·도서관·호텔 등의 실루엣, 정면 구성, 색과 재질, 생활 디테일, 축소 규칙, 피해야 할 표현
- 소리: 직접 녹음할 ASMR 효과음 목록
- 번역: 영어·일본어 진행률과 남은 영역
- 출시: 사이트·앱·Google Play 내부 테스트 확인 목록

체크 상태와 메모는 브라우저의 로컬 저장소에 보관됩니다. 다른 휴대폰으로 옮길 때는 사이트 하단의 `백업 파일 받기`와 `백업 불러오기`를 사용합니다.

## GitHub Pages 배포

이 저장소에는 `.github/workflows/pages.yml`이 들어 있습니다. GitHub 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 선택하면 `main` 브랜치가 갱신될 때 자동 배포됩니다.
