# 프로젝트 작업판

여러 프로젝트의 제작 자산, 디렉팅과 반복해서 쓰는 문서를 휴대폰으로 빠르게 찾아보는 작업판입니다.

- 프로젝트 → 그림·사운드·출시·문서·이메일 → 하위 분류 순서의 메뉴
- 건물 외관·집 외관·건물 내부·마을 배경·취향사전 아이콘·UI 부품을 단계별로 탐색
- 마을 배경은 도시·해안가·백화점 내부·유럽풍·주택가·전원·판타지·계절로 다시 분류
- 이모지로 빠르게 구분하는 얇은 작업 목록과, 눌렀을 때만 여는 짧은 미술 디렉팅
- 그림 종류에 맞는 실제 픽셀 크기의 백지 PNG 가이드 다운로드
- 음악, 버튼, 음식, 생활, 공간 환경음을 묶은 ASMR 사운드 제작 목록
- 베타 안내 이메일 등 붙여넣기용 문서와 복사 버튼
- 완료 체크·진행률·로컬 완료 기록 없이 자료 열람에만 집중
- GPT·Codex 운영 규칙과 복사용 프롬프트 제공

공개 사이트는 GitHub Pages로 배포합니다.
