# 해야 할 것

여러 프로젝트에서 사용자가 아직 해야 하는 결과물과 반복해서 쓰는 문서를 휴대폰으로 확인하는 작업판입니다.

- 프로젝트별 필터
- 전체와 그림·음악/효과음·출시·문서별 `완료/전체` 진행률
- 건물 외관·내부, 취향사전 아이콘, UI 등 하위 분류
- 결과물 하나당 체크 하나만 사용하는 단순 완료 표시
- 그림을 누르면 구체적인 미술 디렉팅 표시
- 녹음할 음악·효과음과 출시 준비 목록
- 베타 안내 이메일 등 붙여넣기용 문서와 복사 버튼
- 완료된 작업은 활성 목록에서 제거하고 누적 진행률은 유지
- GPT·Codex 운영 규칙과 복사용 프롬프트 제공

공개 사이트는 GitHub Pages로 배포합니다.
